# Pi Network Monitor Project

## Summary
This project was definately a challenge but I had a lot of fun doing it. I was able to use python skills as well as get some reps in with freecad.
The code I put together is pretty simple. It is a flask application with all the customizable parts in the fetchy.py script. This script is where you can load in
your custom variables into the hosts dictionary. I left mine in for example but feel free to go wild and use my code as a starting point. I'd love to eventually figure out how to make a custom pi image or something but this serves as a great first iteration. I wrote a Dockerfile so you could run this with docker if you didn't want to just run the script. Included in this repository is the cad file for the monitor I designed as well as the 19 inch model I was working on. I also added in the Freecad files I added if you wanted to customize those as well. If you have any issues you can always make a request here or email me at josh@wattstech.io

### How to use
I put the pi into kiosk mode and pointed at the website created with this script. As long as the pi can get to the website you should be good to go. You can make a kiosk out of any pc. The pi was just a cheap option I had that was easily accessible.
